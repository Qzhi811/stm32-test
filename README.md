# STM32 流水灯与按键方向控制

RoboMaster 电控考核 / 课后作业项目。

## 📌 项目简介
基于 STM32F103C8T6 最小系统板与面包板搭建的 GPIO 输入输出综合实验：
1. **基础实现**：控制至少 4 个 LED 实现流水灯依次点亮熄灭效果。
2. **进阶实现**：通过 GPIO 输入检测轻触按键触发，按下按键即可实时改变流水灯的流动方向（正向/反向切换）。

## 🛠️ 硬件引脚分配
- **LED1**：`PA0`（低电平点亮）
- **LED2**：`PA1`（低电平点亮）
- **LED3**：`PA2`（低电平点亮）
- **LED4**：`PA3`（低电平点亮）
- **KEY1**：`PB1`（上拉输入，按键按下接地产生低电平）
- **供电**：`3.3V` 与 `GND` 连接面包板供电轨

## 💻 软件架构与实现细节
- 采用 STM32 标准外设库（StdPeriph Driver）。
- 延时基于 ARM Cortex-M3 内核的 **SysTick 滴答定时器** 实现微秒与毫秒级高精度延时。
- 按键检测采用 **软件延时消抖** 与 **松手检测** 机制，并在流水灯延时期间进行高频轮询，保证按键随按随响应、不卡顿、不漏检。

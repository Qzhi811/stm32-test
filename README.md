# RoboMaster 电控新生大作业 - 双轴云台姿态解算与增量控制

本项目为 RoboMaster 战队电控组选拔/新生研讨课大作业完整工程。

## 一、作业完成情况

| 考核项目 | 要求说明 | 完成状态 | 核心实现 |
| :--- | :--- | :---: | :--- |
| **必做任务一 (50分)** | 基于六轴陀螺仪实现姿态解算，通过 OLED / 串口实时显示 | **已完成** | MPU6500 I2C 驱动 + 开机零偏校准 + 一阶互补滤波算法（$\alpha=0.96$），OLED 4 行实时显示 Pitch / Roll / Yaw 与舵机状态，串口 10Hz 遥测输出。 |
| **必做任务二 (50分)** | PWM 驱动舵机云台，通过串口实现增量控制（单步移动） | **已完成** | TIM2 产生 50Hz PWM，串口接收字符指令：W（Pitch +5°）、S（Pitch -5°）、A（Yaw -5°）、D（Yaw +5°）、R（复位 90°）。 |
| **进阶拓展项** | 闭环控制算法（PID）实现双轴云台姿态闭环自稳 | **已完成** | 内置位置式姿态 PID 控制器，串口发送 C 可一键开启/关闭闭环自稳模式，抵抗外力扰动与机身晃动。 |
| **配套上位机** | 电脑端可视化监控与控制工具 | **已完成** | 提供专属桌面控制软件《RM云台控制助手》，具备大屏仪表卡片、按键/快捷键控制与日志流显示。 |

## 三、目录结构

`	ext
├── Hardware/        # 外设驱动层
│   ├── Attitude.c/.h    # 姿态互补滤波解算与 PID 控制器
│   ├── MPU6050.c/.h     # MPU6050/6500 传感器驱动与寄存器配置
│   ├── MyI2C.c/.h       # 软件模拟 I2C 底层时序
│   ├── OLED.c/.h        # 0.96寸 OLED 屏幕驱动与字符显示
│   ├── Serial.c/.h      # USART1 串口驱动、printf 重定向与单字符中断
│   └── Servo.c/.h       # 定时器 TIM2 PWM 舵机驱动与增量调节
├── System/          # 延时与系统组件 (Delay.c/.h)
├── User/            # 用户主逻辑与中断服务函数 (main.c, stm32f10x_it.c)
├── Start/           # STM32 启动文件与内核支持库
├── Library/         # STM32F10x 标准外设固件库
├── Project.uvprojx  # Keil uVision5 工程文件
├── RM云台控制助手.exe # 专属电脑端上位机控制软件
└── README.md        # 项目工程文档
`

## 四、编译与使用说明

1. 打开 Project.uvprojx。
2. 确保已在 **Options for Target -> Target** 勾选 **Use MicroLIB**。
3. 点击 **Build (F7)** 编译，点击 **Download (F8)** 烧录到单片机。
4. 核心板平放静止 2 秒完成陀螺仪零漂校准，随后 OLED 实时显示姿态角。
5. 双击打开 RM云台控制助手.exe，选择对应 COM 口即可进行增量控制与 PID 自稳体验。
